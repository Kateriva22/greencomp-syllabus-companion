# GreenComp Syllabus Companion — ξεκίνα από εδώ

Αυτός ο φάκελος είναι το ασφαλές starter pack για την πρώτη έκδοση της εφαρμογής.

## Τι περιέχει

- `CLAUDE.md`: οι σταθερές οδηγίες που διαβάζει αυτόματα το Claude Code.
- `PROJECT_BRIEF.md`: τι ακριβώς πρέπει να κατασκευαστεί στην πρώτη φάση.
- `SECURITY_AND_PRIVACY.md`: οι απαράβατοι κανόνες ιδιωτικότητας και offline λειτουργίας.
- `CLAUDE_FIRST_PROMPT.txt`: το μοναδικό μήνυμα που θα επικολλήσεις στο Claude Code.
- `reference/`: δημόσιο/γενικό πλαίσιο GreenComp και European Schools, καθώς και το σχήμα της απάντησης.
- `test-cases/test-case-01/`: συνθετικό syllabus και η αναμενόμενη σωστή αξιολόγησή του.

## Τι κάνεις εσύ

1. Κατέβασε και αποσυμπίεσε το ZIP σε έναν νέο φάκελο στον υπολογιστή σου.
2. Άνοιξε **αυτόν τον φάκελο** στο Claude Code — όχι ολόκληρο τον φάκελο εργασίας ή τα προσωπικά σου αρχεία.
3. Άνοιξε το `CLAUDE_FIRST_PROMPT.txt`, αντέγραψε το κείμενο και επικόλλησέ το στο Claude Code.
4. Άφησε το Claude να δημιουργήσει την εφαρμογή μόνο μέσα σε νέο υποφάκελο `app/`.
5. Όταν ολοκληρώσει, κράτησε το τελικό report του. Θα το ελέγξουμε μαζί πριν χρησιμοποιηθεί με πραγματικό syllabus.

## Πολύ σημαντικό

Το **Claude Code δεν λειτουργεί offline** κατά την ανάπτυξη. Γι’ αυτό το starter pack περιέχει μόνο συνθετικά δεδομένα και ασφαλές πλαίσιο. Μην προσθέσεις:

- πραγματικό ή μη δημοσιευμένο syllabus,
- στοιχεία μαθητών ή εκπαιδευτικών,
- εσωτερικά drafts, πρακτικά ή έγγραφα εργασίας,
- το APSP ή το draft του strategic framework χωρίς προηγούμενη θεσμική έγκριση.

Η εφαρμογή που θα κατασκευαστεί, αντίθετα, πρέπει να λειτουργεί τοπικά/offline και να μη μεταδίδει τα syllabus που ανοίγει ο χρήστης.

## Αν δεν έχεις εγκατεστημένο Claude Code

Σταμάτα σε αυτό το σημείο. Η εγκατάσταση και το άνοιγμα του σωστού φακέλου είναι το επόμενο πρακτικό βήμα· δεν χρειάζεται να μεταφέρεις τα αρχεία σε ένα απλό Claude.ai chat ή Artifact.
