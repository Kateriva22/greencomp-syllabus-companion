## Non-negotiable rules

- Implement **Phase 1 only**.
- Create all application source code inside `app/`.
- Do not modify files outside this starter-pack folder.
- No backend, database, account, authentication, analytics, telemetry or remote AI/API calls.
- No runtime network request is allowed. File parsing and analysis must occur in the browser.
- Never add real, personal, confidential or unpublished school data to tests, prompts, logs or fixtures.
- Keep the teacher in control: suggestions require explicit Accept, Edit or Reject actions.
- GreenComp is non-prescriptive. Do not treat all 12 competences as compulsory in every syllabus.
- Run automated tests and verify the production build before reporting completion.
- Stop after Phase 1 and report what was built, tested, deferred and still risky.
