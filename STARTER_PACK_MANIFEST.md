# Starter-pack manifest

## Safe development inputs

- Project and privacy requirements.
- Public/general European Schools context.
- GreenComp competence names and working descriptors.
- Synthetic Primary European Hours syllabus.
- Human-validated gold-standard findings for the synthetic syllabus.

## Deliberately excluded

- Real teacher-created syllabi.
- Pupil, parent or staff information.
- Internal working drafts and meeting records.
- APSP 2026-2027 source file.
- Strategic framework working-draft source file.
- Uploaded official syllabus PDFs; these are not required for Phase 1 implementation.

## Intended use

Use this pack only to build and test Phase 1. Add further reference material only after confirming that it is public or institutionally approved for the chosen development service.
